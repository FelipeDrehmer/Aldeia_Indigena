Site da Semana Cultural Guarani

Este projeto é um site criado para divulgar a Semana Cultural Guarani e valorizar a cultura indígena da região de Diamante do Oeste (PR). O site reúne informações sobre eventos, história das aldeias, língua Guarani, jogos educativos e conteúdos produzidos pela comunidade.
Principais recursos:

    -Página da semana cultural atual e anteriores

    -Galeria de fotos e vídeos

    -Dicionário básico Guarani

    -Formulário para agendamento de visitas

    -Integração com redes sociais

    -Área para envio de novos conteúdos

Feito para professores, alunos e todos que querem conhecer e respeitar a cultura Guarani.
